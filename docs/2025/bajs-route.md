# BajsRoute (BInspired)

!!! info inline end "Poveznica"
    [https://bajsroute.info/](https://bajsroute.info/)

Tim iz BInspired izradio je aplikaciju za Android uređaje koja omogućuje
planiranje vožnji koristeći sustav javnih bicikala Bajs. Aplikacija omogućuje
planiranje Bajs vožnji korištenjem otvorenih podataka Grada Zagreba i podataka
dostupnih preko OpenStreetMap servisa, te ocjenjivanje pojedinih dionica
od strane korisnika aplikacije.

Aplikaciju je moguće preuzeti u trgovini
[Google Play](https://play.google.com/store/apps/details?id=com.binspired.bajsroute).

# Zg Air (Neverin)

!!! info inline end "Poveznica"
    [https://www.zagreb-air.com/](https://www.zagreb-air.com/)

Tim iz Neverina izradio je interaktivnu kartu kvalitete zraka u gradu
koja objedinjava podatke iz različitih javno dostupnih izvora.
Uz prikaz trenutnog stanja, stranica omogućuje pregled povijesnih podataka,
a postoji i mogućnost dohvaćanja podataka putem API poziva.

Više informacija možete pronaći na samoj
[stranici](https://www.zagreb-air.com/).

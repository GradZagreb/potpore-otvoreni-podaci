# Urban Score Zagreb (Part Wolf)

!!! info inline end "Poveznica"
    [https://urbanscorezagreb.com/](https://urbanscorezagreb.com/)

Tim iz Part Wolf izradio je servis _Urban Score Zagreb_
koji korisnicima omogućuje izradu procjene dostupnosti sadržaja
koji se nalaze unutar 15 minuta hoda od odabrane lokacije. Interaktivni web
servis korisnicima omogućuje odabir vrsta sadržaja koji ih zanimaju
(poput škola, zdravstvenih ili sportskih ustanova) te prikazuje udaljenosti
od odabrane lokacije od traženih sadržaja.

Više informacija možete pronaći na
[stranicama projekta](https://urbanscore.info/).
